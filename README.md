## Products I've built

### [CourtHubs](https://courthubs.com)
All-in-one management platform for court sports clubs (beach tennis, padel, tennis, pickleball, futsal and footvolley). It replaces WhatsApp and spreadsheets with a single dashboard: online bookings, scheduling, students and classes, bar tabs and financial management.

- **Discovery:** conversations with club owners, plus research with players and coaches to prioritize features
- **Status:** live with a pilot club
- **Stack:** React (PWA) · Bun + TypeScript · PostgreSQL · React Native/Expo (in progress)

### [Comissy](https://comissy.com.br)
Commission tracking for independent sales professionals, built to replace the Excel spreadsheets they rely on.

- **Status:** live with a pilot customer
- **Stack:** React + Vite · Node.js + Express · PostgreSQL

Both products are built with Claude Code: I write the specs and implementation plans, and use AI to move fast while owning the product decisions. Their source code is private.
